## 🚀 GitHub Pages 部署教學

本系統為 **純靜態前端架構**，無任何後端伺服器與資料庫依賴，可直接推送到 GitHub 並開啟 GitHub Pages 免費發布！

### 步驟 1：初始化 Git 倉庫並提交程式碼
在終端機（PowerShell 或 CMD）中執行：
```bash
git init
git add .
git commit -m "feat: 投資型保險商品業務員資格測驗模擬考試系統建置完成"
```

### 步驟 2：關聯 GitHub 遠端倉庫並推送
在 GitHub 上新建一個名為 `Hao-INV`（或自訂名稱）的公開倉庫，然後執行：
```bash
git branch -M main
git remote add origin https://github.com/您的GitHub帳號/您的倉庫名稱.git
git push -u origin main
```

### 步驟 3：在 GitHub 開啟 GitHub Pages 發布
1. 進入該 GitHub 倉庫頁面，點擊上方 **Settings**（設定）。
2. 在左側選單點擊 **Pages**。
3. 在 **Build and deployment** 下方的 **Branch** 選擇 `main`，資料夾選擇 `/ (root)`。
4. 點擊 **Save**。
5. 等待 1~2 分鐘，即可透過專屬網址上線使用：
   `https://您的GitHub帳號.github.io/您的倉庫名稱/`
